# FinWorld App

FinWorld is a Vite-based web app built with TypeScript and packaged for Android using Capacitor.

## Tech Stack

- Vite
- TypeScript
- Capacitor for Android
- CSS for styling

## Prerequisites

Before running the project, make sure you have:

- Node.js 18+ and npm
- Android Studio installed with Android SDK
- Java JDK configured for Android builds

## Project Structure

```bash
finworld-app/
├── android/              # Android project generated by Capacitor
├── public/               # Static public assets
├── src/                  # Application source code
├── index.html            # App entry HTML
├── capacitor.config.ts   # Capacitor configuration
├── package.json          # Scripts and dependencies
├── tsconfig.json         # TypeScript configuration
├── vite.config.*        # Vite config (if present)
└── dist/                 # Production build output
```

## Installation

From the project root:

```bash
cd finworld-app
npm install
```

## Run the App in the Browser

Start the Vite development server:

```bash
npm run dev
```

This will start the app locally, usually on:

```bash
http://localhost:5173
```

## Production Build

To build the app for production:

```bash
npm run build
```

This runs TypeScript compilation and then creates the production bundle in the `dist/` directory.

## Sync with Android

After building the web app, sync it with the Android project:

```bash
npx cap sync android
```

If the Android project has not been generated yet, run:

```bash
npx cap add android
```

## Open the Android Project

To open the Android project in Android Studio:

```bash
npx cap open android
```

## Useful Commands

```bash
# Start local dev server
npm run dev

# Build production bundle
npm run build

# Preview production build locally
npm run preview

# Sync web build to native Android project
npx cap sync android

# Open Android Studio
npx cap open android
```

## Notes

- The app is configured with the bundle ID `com.finworld.app`.
- The Capacitor web directory is set to `dist`, which matches the Vite production build output.
- For Android development, keep Android Studio and the SDK up to date and ensure your environment variables are configured correctly.

## Troubleshooting

If the app does not start:

1. Make sure dependencies are installed: `npm install`
2. Confirm Node.js version is compatible
3. Check if Android Studio and SDK are installed for native builds
4. Re-run `npx cap sync android` after major changes to web code
